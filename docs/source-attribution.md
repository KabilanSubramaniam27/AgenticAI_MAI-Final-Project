# Source attribution

Corpus: English Wikivoyage, by Wikivoyage contributors, licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). See [Wikivoyage's reuse policy](https://en.wikivoyage.org/wiki/Wikivoyage:Copyleft).

Each page, section, chunk, and retrieval result carries the article URL, revision permalink, history URL, source revision timestamp, retrieval timestamp, attribution, license URL, and modification note. Guide text has been parsed, normalized and chunked. Preserve attribution and applicable share-alike requirements when redistributing source-derived text. Images are excluded.

A page's edit timestamp and its latest HTTP check are not verification of every listed price, opening time, or recommendation. Guide price strings are stored as historical source guidance; no live availability/pricing/forecast claim is made. Unknown fields remain absent or `unknown`.

Tests explicitly distinguish synthetic examples from attributed excerpts of collected revisions. The generated raw corpus is not committed to the repository.
